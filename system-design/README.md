# System Design

System design preparation with a focus on AI powered systems that a Forward Deployed Engineer would build and deploy inside a customer environment.

## Focus areas

- **Fundamentals**: APIs, databases, caching, queues, load balancing, and consistency tradeoffs.
- **LLM system design**: retrieval augmented generation (RAG), vector stores, chunking, embeddings, context windows, and caching for cost.
- **Agents and tools**: tool calling, orchestration, retries, guardrails, and human in the loop.
- **Data pipelines**: ingestion, transformation, and syncing with customer data sources.
- **Deployment**: on premise versus cloud, VPC, security, secrets, and observability.
- **Evaluation and monitoring**: offline evals, online metrics, feedback loops, and drift.
- **Cost and latency**: token budgets, model selection, batching, and streaming.

## Suggested plan

1. Learn the fundamentals with one structured course or book.
2. Work through 8 to 10 classic designs (news feed, chat, rate limiter, search).
3. Do 5 LLM specific designs (document Q and A, support agent, code assistant, data extraction, internal knowledge search).
4. Practice explaining each design out loud in 30 minutes.
