# AI and Machine Learning

Applied AI knowledge for the AI Forward Deployed Engineer role. The bar is practical fluency with large language models and the systems around them, not research depth.

## Focus areas

- **LLM basics**: tokens, context windows, temperature, sampling, and model families.
- **Prompt engineering**: system prompts, few shot examples, structured output, and JSON mode.
- **Retrieval augmented generation (RAG)**: embeddings, chunking, vector search, reranking, and citations.
- **Agents**: tool calling, planning, multi step workflows, and failure handling.
- **Evaluation**: building eval sets, LLM as judge, rubrics, regression testing, and human review.
- **Fine tuning and adaptation**: when to fine tune, supervised fine tuning, and preference tuning at a high level.
- **Context engineering**: managing long context, memory, and state.
- **Safety and guardrails**: prompt injection, data leakage, PII handling, and refusal behavior.
- **Cost and performance**: model selection, caching, batching, and streaming.

## Suggested plan

1. Read the core documentation for at least one major LLM provider.
2. Build a small RAG app over your own notes.
3. Build a simple tool calling agent with 2 to 3 tools.
4. Write an eval set for one of your apps and measure changes.
