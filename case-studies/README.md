# Case Studies

Mock customer scenarios for practicing the Forward Deployed Engineer customer facing round. Each case study presents an ambiguous business problem. Your job is to scope it, propose a pilot, and outline a technical design.

## How to use a case study

1. Read the scenario once and note your first questions.
2. Spend 10 minutes on clarifying questions and assumptions.
3. Define success metrics and a pilot scope.
4. Sketch the technical design: data sources, model, retrieval, integration, and evaluation.
5. List risks and how you would handle them.
6. Write a one page proposal.
