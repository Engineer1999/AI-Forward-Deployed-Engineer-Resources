# Contributing

Thanks for helping other AI Forward Deployed Engineer candidates prepare. This guide covers how to add resources and notes.

## Ways to contribute

- Add a high quality resource: a book, course, article, video, repository, or tool.
- Add study notes, summaries, or cheat sheets.
- Add a company interview guide based on a real, recent loop.
- Add a case study or mock customer scenario with a solution walkthrough.
- Fix errors, broken links, or outdated information.

## Folder conventions

Place your contribution in the folder that matches its topic:

- `coding/` for algorithms, data structures, and language notes.
- `system-design/` for architecture and LLM system design.
- `ai-ml/` for LLMs, RAG, agents, evaluations, and fine tuning.
- `forward-deployed/` for the customer facing craft.
- `take-home/` for project guidance and sample builds.
- `behavioral/` for stories and frameworks.
- `case-studies/` for scenario walkthroughs.
- `company-guides/` for company specific loops.
- `resources/` for curated external links.
- `templates/` for reusable templates.

The `journey/` folder is the maintainer's personal log. Please do not add entries there, but feel free to link to it.

## Style

- Use clear Markdown headings and short paragraphs.
- Do not use the em dash character. Use commas, colons, parentheses, or the word "to".
- Prefer primary sources and link directly to them.
- Add a one line summary for every link that says why it is useful.
- Keep filenames lowercase with hyphens, for example `llm-system-design.md`.
- Do not commit copyrighted PDFs, paid course material, or proprietary interview questions under NDA.

## Adding a resource to a list

Use this format inside the relevant `README.md`:

```
- [Resource title](https://example.com) by Author. One line on what it covers and why it helps.
```

## Pull request checklist

- [ ] The contribution is in the correct folder.
- [ ] All links work and point to the primary source.
- [ ] Every link has a one line summary.
- [ ] No em dash characters.
- [ ] No copyrighted or NDA protected material.
- [ ] Filenames are lowercase with hyphens.
