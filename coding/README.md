# Coding

Practical coding preparation for the AI Forward Deployed Engineer interview. FDE coding rounds lean toward real work: parsing data, calling APIs, transforming records, and writing clean, testable code under time pressure. Hard graph and dynamic programming puzzles are less common but still appear at some companies.

## Focus areas

- **Data manipulation**: strings, arrays, hash maps, grouping, and aggregation.
- **Parsing and file formats**: JSON, CSV, logs, and nested structures.
- **API work**: pagination, retries, rate limits, and error handling.
- **Code quality**: naming, small functions, tests, and readable structure.
- **Core algorithms**: sorting, searching, recursion, trees, and graphs for the companies that test them.
- **A primary language**: pick one (often Python) and know its standard library well.

## Start here: coding patterns

Work through [`patterns/`](patterns/) first. It covers 16 reusable patterns for data structure and algorithm questions, each with a Python template, worked examples, and a practice list. Learning to recognize the pattern behind a problem is the fastest way to improve.

## Suggested plan

1. Read every page in [`patterns/`](patterns/) and type each template from memory.
2. Warm up with 20 to 30 easy and medium data manipulation problems.
3. Practice one timed 45 minute problem every other day.
4. Build a small script that consumes a public API end to end.
5. Review your solutions for readability and add tests.
