# Prep Journey

My personal log of preparing for AI Forward Deployed Engineer interviews, shared in public so the process is transparent and useful to others.

## How this is organized

- `weekly/` holds dated weekly retrospectives.
- `logs/` holds shorter daily or session notes.
- `lessons.md` is a running list of the biggest lessons.

Entries use the format `YYYY-MM-DD-short-title.md`.

## Start here

- [`lessons.md`](lessons.md) for the condensed takeaways.
- The most recent file in `weekly/` for where I am now.
