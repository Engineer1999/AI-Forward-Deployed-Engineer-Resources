# Take Home Projects

Many AI Forward Deployed Engineer loops include a take home project or a timed live build using an LLM API. Reviewers look at product sense, code quality, and how you communicate decisions, not just whether it works.

## Common prompts

- Build a document question and answer tool over a small corpus.
- Extract structured data from messy text or PDFs.
- Build a small agent that uses two or three tools to complete a task.
- Summarize or classify a dataset and expose the result through an API or simple UI.

## What reviewers score

- **Does it work**: the core flow runs and handles obvious edge cases.
- **Code quality**: clear structure, naming, and a few meaningful tests.
- **Product judgment**: sensible scope, good defaults, and a usable interface.
- **Communication**: a README that explains the approach, tradeoffs, and what you would do next.
- **AI specifics**: prompt design, handling of model errors, cost awareness, and a basic evaluation.

## Checklist before you submit

- [ ] A README with setup steps, approach, tradeoffs, and next steps.
- [ ] Environment variables and secrets handled cleanly, no keys committed.
- [ ] Error handling for API failures and bad input.
- [ ] At least a small evaluation or test of output quality.
- [ ] A short demo recording or screenshots if allowed.
